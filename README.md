# 共居 · Showtime

公共空间事件反馈平台，Python 3.12+，零第三方运行依赖。按地点记录问题，不建立人物档案。

## 功能

- 厕所吸烟：事发楼栋、楼层；洗衣机使用问题：楼栋、楼层、东／西侧、可选编号。
- 上传者必填本人楼栋、宿舍号，仅管理员接口返回。公开页面匿名。
- 照片在浏览器手动框选不透明遮挡，不会自动识别人脸。原图不上传；画布输出 PNG，服务端再次验证并移除所有非必要 PNG 元数据块。
- 未审核事件及照片不对外提供；管理员确认照片、文字、地点和规则后发布，可改为处理中、已处理、驳回、撤回或永久删除。
- SQLite 持久化，包括照片；仅管理员具有发布权限。支持按类型、楼栋、楼层、状态筛选。

## 部署到服务器

GitHub 仓库用于保存代码；GitHub Pages 无法运行本项目的私密数据、审核和上传接口。需要支持 Python 或 Docker 的服务器。

1. 克隆仓库，在项目根目录创建 `.env`（不要提交），设置 `ADMIN_PASSWORD=至少16位随机密码`。
2. 运行 `docker compose up -d --build`。
3. 通过 Caddy / Nginx 将 HTTPS 域名反向代理到 `127.0.0.1:8000`。默认 Cookie 要求 HTTPS。
4. 网站右上角“管理入口”输入密码即可审核。设置反向代理请求大小为至少 9 MB，连接及读取超时建议 30 秒。为上传和登录配置真实客户端 IP 限流；应用自身按直连 IP 做基础限流，代理后所有人可能共享额度。
5. 定期备份 `showtime-data` 卷；包含住宿信息，应限制访问及备份权限。删除数据应同时遵循备份保留规则。管理员需定期清理不再用于核实的事件和住宿信息，申请撤下可通过提交事件编号及原因受理。

管理员会话有效期 1 小时，仅保存在进程内；应用重启后需重新登录。推荐单实例部署，关闭公共注册式管理权限。不提供默认密码。

## 本地运行

```bash
export ADMIN_PASSWORD='replace-with-a-long-random-password'
export COOKIE_SECURE=0  # 仅本地 HTTP 测试
python server.py
```

打开 http://localhost:8000 。生产环境保持 `COOKIE_SECURE=1`，使用 HTTPS；不要把本地测试配置直接暴露公网。

## 验证

```bash
python -m unittest discover -s tests -v
node --check static/app.js
```

不自动判断违规、识别人脸或提取照片身份。管理员须核实事实、场所规则与脱敏程度；不能安全公开的记录应驳回或删除。
